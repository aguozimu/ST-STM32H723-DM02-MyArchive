# 麦轮底盘惯导位置闭环第一版设计说明（最简实现）

> 修订日期：2026-09-21
> 核对依据：当前工程源码与《ZDT_X42S 第二代闭环步进电机用户手册 V1.0.5（260527）》
> 工程根目录：`F:\STM32H723\H7_BSP-main\H7_BSP-main`
> 本文只做一件最简的事：**INS 里融合陀螺仪和四轮里程计得到 `x / y / yaw`，Chassis 用这个位姿把车开到指定相对位置。**

---

## 1. 总体思路

从上到下只有三个角色，每个角色只干一件事：

| 层 | 文件 | 职责 |
|---|---|---|
| INS | `User_File/Application/INS/INS.h/.cpp`（新增） | 100 Hz 融合 `gyro_z` 和四轮位置反馈，输出 `x / y / yaw` |
| Chassis | `User_File/Application/Chassis/Chassis.h/.cpp` | 麦轮运动学 + 最简单的距离闭环 `RunToRelativePose()` |
| ZDT | `User_File/Device/Peripheral/Motor/ZDTmotor/` | CAN 收发、速度命令、编码器位置反馈（已实现，直接复用） |

数据流：

```text
四轮 0x36 位置反馈 --> 麦轮正运动学 dx_body / dy_body / dyaw_wheel --+
                                                                     +--> INS 最简融合 --> x, y, yaw
BMI088 gyro_z (rad/s) --> dyaw_gyro = gyro_z * dt -------------------+

x, y, yaw --> RunToRelativePose() 的 P 控制 --> vx, vy, wz
          --> 麦轮逆运动学 --> 四轮 F6 速度命令 --> 同步触发
```

第一版**一律不做**：EKF/ESKF、打滑检测、电机离线/过温/过流判定、故障状态机、锁轴/失能策略、轨迹规划、速度前馈、加速度限制、视觉融合。这些要么不需要，要么以后再说。

## 2. 坐标系与单位

沿用现有 `Class_Chassis::SetVelocity()` 的定义：

- 机体系：`+x` 向右，`+y` 向前，`+z` 向上，`+omega` 逆时针为正；
- 世界系：复位瞬间的车体坐标系，之后不再改变；
- 单位：长度 m，速度 m/s，角度 rad，角速度 rad/s；
- 四轮数组顺序固定为左前、右前、左后、右后（`Chassis_Wheel_LeftFront ... Chassis_Wheel_RightRear`）。

机体系与世界系的换算只用 yaw 一个角度：

```text
dx_world = cos(yaw) * dx_body - sin(yaw) * dy_body
dy_world = sin(yaw) * dx_body + cos(yaw) * dy_body

dx_body =  cos(yaw) * dx_world + sin(yaw) * dy_world
dy_body = -sin(yaw) * dx_world + cos(yaw) * dy_world
```

复位时 `x = 0, y = 0, yaw = 0`，此时车头方向就是 `+y_world`。

## 5. INS：最简融合

### 5.1 输入

| 来源 | 接口 | 含义 |
|---|---|---|
| 四轮位置 | `APP_Chassis.GetWheelFeedback().position_deg[i]` | 已应用极性，单位度 |
| 陀螺仪 | `BSP_BMI088.Get_Gyro_Body().Data[2]` | VQF 修正后的机体系 z 轴角速度，rad/s |
| 时间 | `SYS_Timestamp.Get_Now_Microsecond()` | 64 位微秒时间戳 |

### 5.2 公式

轮子位移（只做单位换算和 ±180 度回绕处理，不做任何有效性判断）：

```text
d_deg = position_deg_now - position_deg_last      // 绝对值超过 180 时按 360 修正
ds    = d_deg * pi / 180 / gear_ratio * wheel_radius_m        // 单位 m
```

麦轮正运动学（与 `SetVelocity()` 的逆运动学严格对称）：

```text
dx_body    = ( ds[LF] - ds[RF] - ds[LR] + ds[RR]) / 4
dy_body    = ( ds[LF] + ds[RF] + ds[LR] + ds[RR]) / 4
dyaw_wheel = (-ds[LF] + ds[RF] - ds[LR] + ds[RR]) / (4 * (half_length + half_width))
```

航向互补融合（最简，一个常数权重）：

```text
dyaw_gyro = gyro_z * dt
dyaw      = 0.98 * dyaw_gyro + 0.02 * dyaw_wheel
```

位置积分（用周期中点航向，边走边转时误差更小）：

```text
yaw_mid = yaw + 0.5 * dyaw
x   += cos(yaw_mid) * dx_body - sin(yaw_mid) * dy_body
y   += sin(yaw_mid) * dx_body + cos(yaw_mid) * dy_body
yaw  = WrapAngle(yaw + dyaw)
```

`User_File/Application/INS/INS.cpp`：

```cpp
#include "INS.h"
#include "bsp_bmi088.h"
#include "sys_timestamp.h"

#include <cmath>

namespace
{
constexpr float PI_F = 3.14159265358979f;
constexpr float GYRO_WEIGHT = 0.98f;   // 越大越信任陀螺仪

float Wrap_Angle(float angle)
{
    while (angle > PI_F)  { angle -= 2.0f * PI_F; }
    while (angle < -PI_F) { angle += 2.0f * PI_F; }
    return angle;
}
} // namespace

Class_INS APP_INS;

void Class_INS::Init(const Struct_Chassis_Config &config)
{
    half_length = config.half_length;
    half_width = config.half_width;
    wheel_radius_m = config.wheel_radius_m;
    gear_ratio = config.gear_ratio;
    ResetPose();
    first_sample = true;
}

void Class_INS::ResetPose()
{
    state.x_m = 0.0f;
    state.y_m = 0.0f;
    state.yaw_rad = 0.0f;
    state.valid = false;
    last_timestamp_us = 0U;
}

Struct_INS_State Class_INS::GetState() const
{
    return state;
}

bool Class_INS::Update()
{
    Struct_Chassis_Wheel_Feedback wheel{};
    APP_Chassis.GetWheelFeedback(wheel);

    const uint64_t now_us = SYS_Timestamp.Get_Now_Microsecond();

    // 第一帧只建立基准，不产生位移。
    if (first_sample || (last_timestamp_us == 0U))
    {
        for (uint8_t i = 0U; i < CHASSIS_WHEEL_COUNT; ++i)
        {
            last_position_deg[i] = wheel.position_deg[i];
        }
        last_timestamp_us = now_us;
        first_sample = false;
        state.valid = true;
        return true;
    }

    const float dt = static_cast<float>(now_us - last_timestamp_us) * 1.0e-6f;
    if (dt <= 0.0f)
    {
        return false;
    }
    last_timestamp_us = now_us;

    // 四轮位移，单位 m。
    float ds[CHASSIS_WHEEL_COUNT] = {0.0f};
    for (uint8_t i = 0U; i < CHASSIS_WHEEL_COUNT; ++i)
    {
        float d_deg = wheel.position_deg[i] - last_position_deg[i];
        last_position_deg[i] = wheel.position_deg[i];
        if (d_deg > 180.0f)  { d_deg -= 360.0f; }
        if (d_deg < -180.0f) { d_deg += 360.0f; }
        ds[i] = d_deg * PI_F / 180.0f / gear_ratio * wheel_radius_m;
    }

    // 麦轮正运动学。
    const float dx_body = ( ds[0] - ds[1] - ds[2] + ds[3]) * 0.25f;
    const float dy_body = ( ds[0] + ds[1] + ds[2] + ds[3]) * 0.25f;
    const float rotation_radius = half_length + half_width;
    const float dyaw_wheel =
        (-ds[0] + ds[1] - ds[2] + ds[3]) / (4.0f * rotation_radius);

    // 陀螺仪 + 轮式航向增量互补融合。
    const float gyro_z = BSP_BMI088.Get_Gyro_Body().Data[2];
    const float dyaw = GYRO_WEIGHT * (gyro_z * dt) + (1.0f - GYRO_WEIGHT) * dyaw_wheel;

    // 中点航向积分。
    const float yaw_mid = state.yaw_rad + 0.5f * dyaw;
    state.x_m += std::cos(yaw_mid) * dx_body - std::sin(yaw_mid) * dy_body;
    state.y_m += std::sin(yaw_mid) * dx_body + std::cos(yaw_mid) * dy_body;
    state.yaw_rad = Wrap_Angle(state.yaw_rad + dyaw);
    state.valid = true;
    return true;
}
```

### 5.4 约束

1. `Update()` 只做融合和积分，不判有效、不判超时、不判打滑；
2. 由 InsTask 以 10 ms 周期调用，不要放在控制闭环里；
3. 位置反馈按度处理，超过 180 度的差值按回绕修正，单圈和多圈编码都能用；
4. `ResetPose()` 只清导航原点，不清电机内部计数。

## 6. Chassis：最简距离闭环

### 6.1 接口

```cpp
bool RunToRelativePose(float x, float y, float omega, float distance_m);
```

参数含义：

- `x`、`y`：机体系方向，`+x` 向右、`+y` 向前，**只有方向有意义**，模长不表示距离也不表示速度；
- `distance_m`：需要行进的距离，单位 m；
- `omega`：相对调用瞬间朝向的目标角度，单位 rad，逆时针为正；
- `omega == 0`：只平移，不要求转向；
- `distance_m == 0 && omega != 0`：原地相对旋转；
- `distance_m == 0 && omega == 0`：空操作，直接返回 true；
- `distance_m > 0` 且 `x == 0 && y == 0`：方向未定义，返回 false；
- 出现 NaN/Inf 或 `distance_m < 0`：返回 false。

返回值 `true` 表示已经到位并停止，`false` 表示参数非法、INS 未就绪或超时。

目标点由调用瞬间的位姿算出：

```text
方向归一化: (ux, uy) = (x, y) / sqrt(x*x + y*y)
机体系位移: dx_body = ux * distance_m,  dy_body = uy * distance_m
世界系位移: dx_world = cos(yaw0) * dx_body - sin(yaw0) * dy_body
            dy_world = sin(yaw0) * dx_body + cos(yaw0) * dy_body
目标位姿:   target_x   = x0 + dx_world
            target_y   = y0 + dy_world
            target_yaw = WrapAngle(yaw0 + omega)
```

调用示例：

```cpp
APP_Chassis.RunToRelativePose(0.0f, 1.0f, 0.0f, 1.0f);        // 沿当前前方走 1 m
APP_Chassis.RunToRelativePose(1.0f, 0.0f, 0.0f, 0.5f);        // 沿当前右方横移 0.5 m
APP_Chassis.RunToRelativePose(1.0f, 1.0f, 0.0f, 1.0f);        // 沿右前 45 度走 1 m
APP_Chassis.RunToRelativePose(0.0f, 0.0f, 1.5707963f, 0.0f);  // 原地逆时针转 90 度
```

### 6.2 控制律与停止条件

世界系误差换算到机体系，然后只用 P 控制：

```text
ex_world = target_x - x
ey_world = target_y - y
eyaw     = WrapAngle(target_yaw - yaw)

ex_body =  cos(yaw) * ex_world + sin(yaw) * ey_world
ey_body = -sin(yaw) * ex_world + cos(yaw) * ey_world

vx = clamp(kp_xy  * ex_body, -max_linear_speed_m_s,    +max_linear_speed_m_s)
vy = clamp(kp_xy  * ey_body, -max_linear_speed_m_s,    +max_linear_speed_m_s)
wz = clamp(kp_yaw * eyaw,    -max_angular_speed_rad_s, +max_angular_speed_rad_s)
```

到位判据（三个条件同时满足，然后 `Stop()`）：

```text
abs(ex_world) < 0.02 m
abs(ey_world) < 0.02 m
abs(eyaw)     < 0.05 rad
```

超时退出：累计超过 60 s 仍未到位就 `Stop()` 并返回 false。这只是防止死循环，不是故障检测。

推荐初值：`kp_xy = 1.0 ~ 1.5`、`kp_yaw = 2.0`、周期 10 ms、最大平移速度 `0.3 m/s`、最大角速度 `1.0 rad/s`。

```cpp
bool Class_Chassis::GetWheelFeedback(Struct_Chassis_Wheel_Feedback &feedback) const

bool Class_Chassis::RunToRelativePose(float x, float y, float omega, float distance_m)
{
    if (!std::isfinite(x) || !std::isfinite(y) ||
        !std::isfinite(omega) || !std::isfinite(distance_m) ||
        (distance_m < 0.0f))
    {
        return false;
    }

    const float direction_norm = std::sqrt(x * x + y * y);
    if ((distance_m > 0.0f) && (direction_norm < 1.0e-3f))
    {
        return false;
    }

    const Struct_INS_State start = APP_INS.GetState();
    if (!start.valid)
    {
        return false;
    }

    float dx_body_target = 0.0f;
    float dy_body_target = 0.0f;
    if (direction_norm > 1.0e-3f)
    {
        dx_body_target = x / direction_norm * distance_m;
        dy_body_target = y / direction_norm * distance_m;
    }

    const float start_cos = std::cos(start.yaw_rad);
    const float start_sin = std::sin(start.yaw_rad);
    const float target_x = start.x_m + start_cos * dx_body_target - start_sin * dy_body_target;
    const float target_y = start.y_m + start_sin * dx_body_target + start_cos * dy_body_target;
    const float target_yaw = Wrap_Angle(start.yaw_rad + omega);

    uint32_t elapsed_ms = 0U;
    while (elapsed_ms < TIMEOUT_MS)
    {
        const Struct_INS_State state = APP_INS.GetState();

        const float ex_world = target_x - state.x_m;
        const float ey_world = target_y - state.y_m;
        const float eyaw = Wrap_Angle(target_yaw - state.yaw_rad);

        if ((std::fabs(ex_world) < POSITION_TOLERANCE_M) &&
            (std::fabs(ey_world) < POSITION_TOLERANCE_M) &&
            (std::fabs(eyaw) < YAW_TOLERANCE_RAD))
        {
            Stop();
            return true;
        }

        const float yaw_cos = std::cos(state.yaw_rad);
        const float yaw_sin = std::sin(state.yaw_rad);
        const float ex_body = yaw_cos * ex_world + yaw_sin * ey_world;
        const float ey_body = -yaw_sin * ex_world + yaw_cos * ey_world;

        SetVelocity(Clamp(KP_XY * ex_body, config.max_linear_speed_m_s),
                    Clamp(KP_XY * ey_body, config.max_linear_speed_m_s),
                    Clamp(KP_YAW * eyaw, config.max_angular_speed_rad_s));

        osDelay(CONTROL_PERIOD_MS);
        elapsed_ms += CONTROL_PERIOD_MS;
    }

    Stop();
    return false;
}

bool Class_Chassis::SetWheelPolarity(Enum_Chassis_Wheel wheel, int8_t polarity)
{
    if ((wheel >= CHASSIS_WHEEL_COUNT) ||
        ((polarity != 1) && (polarity != -1)))
    {
        return false;
    }

    Stop();
    motor_config[wheel].polarity = polarity;
    motors[wheel].SetReverse(polarity < 0);
    return true;
}
```

`Init()` 里补一句，把 `speed_to_motor` 由轮径和减速比算出来，调用方不用再手填：

```cpp
config = new_config;
const float speed_to_motor =
    config.gear_ratio * 60.0f / (2.0f * PI_F * config.wheel_radius_m);
...
motor_config[i] = new_motor_config[i];
motor_config[i].speed_to_motor = speed_to_motor;
```

### 6.4 注意事项

1. `RunToRelativePose()` 内部用 `osDelay()`，**只能在 `Control_Task` 里调用**，不能在 InsTask 或 1 ms 回调里调用；
2. 它调用的 `SetVelocity()` 会顺手取消 `RunForSeconds()` 的倒计时，两种运动不会打架；
3. 阻塞期间 InsTask 照常在跑，位姿是实时更新的；
4. 控制参数全部来自 `Struct_Chassis_Config` 和文件内的常数，不要写死在业务代码里；
5. 需要中途停到时，直接调用 `APP_Chassis.Stop()`。

## 8. 底层电机调用（已核对现有代码）

相对位姿闭环不直接发位置命令，仍然走现有速度模式，调用链固定为：

```text
APP_Chassis.RunToRelativePose()
    -> 计算 vx / vy / wz
    -> Class_Chassis::SetVelocity()
    -> 麦轮逆运动学得到四轮轮缘速度
    -> Class_ZDTMotor::SetSpeed(rpm, acceleration, true)   四次，只缓存
    -> Class_ZDTMotor::TriggerSynchronousMotion()          地址 0 广播同步执行
```

停止链路：

```text
Class_Chassis::Stop()
    -> Class_ZDTMotor::Stop(true)                四次，只缓存
    -> Class_ZDTMotor::TriggerSynchronousMotion()
```

编码器反馈链路：

```text
APP_Chassis.ConfigureOdometryFeedback(10U)
    -> Class_ZDTMotor::ConfigurePeriodicFeedback(0x36U, 10U)   四次
    -> 电机每 10 ms 主动返回实时位置
    -> Class_ZDTMotor::FeedbackCallback() -> ParseFeedback()
    -> GetFeedback().position_deg（已应用极性）
    -> APP_Chassis.GetWheelFeedback()
    -> APP_INS.Update()
```

手册要点（《ZDT_X42S 第二代闭环步进电机用户手册 V1.0.5》）：

| 项目 | 结论 |
|---|---|
| CAN 帧 | 经典 CAN 29 位扩展帧，ID 由“地址左移 8 位再按位或上分包号”得到，每包首个数据字节是功能码 |
| 地址 1~4 | Packet 0 的接收 ID 分别为 `0x0100`、`0x0200`、`0x0300`、`0x0400` |
| 位置周期反馈 | `0x11 0x18 0x36 period(2B)`，即 `ConfigurePeriodicFeedback(0x36U, 10U)`；周期写 0 停止 |
| 位置返回 | 字节：`0x36` + 符号(00 正/01 负) + 32 位大端绝对值 + 校验 |
| EMM 位置换算 | 65536 计数/圈，`角度 = 值 * 360 / 65536` |
| EMM 转速 | `0x35` 返回单位 RPM；X 固件为 0.1 RPM |
| 注意 | `pulses_per_revolution = 3200` 是位置命令的脉冲参数，**不能**用于解析 `0x36` 反馈 |

## 9. 极性（正负方向）

### 9.1 现有机制

- `Struct_Chassis_Motor_Config::polarity`：`+1` 正向、`-1` 反向；
- `Class_Chassis::Init()` 里 `motors[i].Init(..., polarity < 0, ...)`；
- `Class_ZDTMotor::SetSpeed()` 按 `reverse` 翻转命令方向；
- `ParseFeedback()` 通过 `ApplyDirection()` 对 `position_deg`、`speed_rpm` 应用同一方向。

所以极性只需要配置一次，命令和反馈会同时翻转，**INS 和正运动学里绝对不要再按左右轮改符号**，否则会二次反向。

### 9.2 实车检查方法

1. 悬空四轮，只给 `polarity = 1`，用 `RunForSeconds(0.0f, 0.2f, 0.0f, 1.0f)` 前进；
2. 观察每个轮子转向，记录哪一个与期望相反，把该轮 `polarity` 改成 `-1`；
3. 落地重复一次前进、横移、原地旋转，确认 `GetWheelFeedback()` 的 `position_deg` 正负与运动方向一致。

### 9.3 运行时极性接口

```cpp
bool SetWheelPolarity(Enum_Chassis_Wheel wheel, int8_t polarity);
```

- 只接受合法车轮枚举和 `+1 / -1`；
- 调用前必须停车；
- 最简实现：给 `Class_ZDTMotor` 加一个只改方向标志的小函数

```cpp
void Class_ZDTMotor::SetReverse(bool value)
{
    reverse = value;
}
```

  然后 `Class_Chassis::SetWheelPolarity()` 调用它，并同步更新 `motor_config[wheel].polarity`；
- 不要重新调用 `Class_ZDTMotor::Init()` 来改极性，那样会重复注册同一个 CAN 回调；
- 正常运行时应优先在 `Init()` 之前把极性配好，这个接口留给台架校准。

## 11. 参数标定

1. **轮径**：让四个轮子走同样的角度，量出实际直线距离，用 `实际距离 / 理论距离` 修正 `wheel_radius_m`；
2. **旋转半径**：原地转 10 圈，比较里程计角度和实际角度，必要时用标定值替代 `half_length + half_width`；
3. **航向权重**：先 `GYRO_WEIGHT = 0.98`，原地旋转看轮式角度和陀螺仪角度差多少，差得大说明轮子打滑或极性配错；
4. **P 参数**：先只跑前进 1 m，`kp_xy` 从 1.0 开始调，超调就减小，收敛慢就加大。
